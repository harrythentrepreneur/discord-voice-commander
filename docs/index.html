Set up

Ready in about ten minutes.

It runs on a computer you own, and your phone connects to it privately. Nothing is hosted for you, and nothing is shared.

Add a Discord bot

Create a bot in the Discord developer portal and invite it to your server.

Run the server

Add your bot token and server ID, then sign in to ChatGPT once.

Open it on your phone

Reach your computer privately with Tailscale. Add the page to your home screen and talk.

# needs Node 20+
U=harrythentrepreneur
npx degit $U/discord-voice-commander dvc
cd dvc && npm install

# add your bot token + server ID
cp .env.example .env

# sign in to ChatGPT (for the voice)
codex login

npm start

# in a second terminal: phone access
tailscale serve 3077
Safety

Safe by default.

It acts with your bot's permissions, so the guard rails are in the code, not just the prompt.

Private, not publicIt listens only on your computer. You reach it through your private Tailscale network, never the open internet.

No destructive actionsIt can't delete other people's messages, ban members or change permissions.

Only posts when you askA post goes out only if you clearly asked for one. Anything else waits for a spoken yes.

Your keys stay homeTokens never reach the browser. It needs no paid API key.

Locked to youAn access code or your Tailscale login, with a lockout after five wrong tries.

Open source, MITSmall and readable. Check every line yourself.
