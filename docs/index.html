Listening…

Everything you'd do in Discord. Out loud.

Say it the way you'd say it to a person. It finds the right channel, even if you only half remember the name.

“What did I miss?”

Catch up

A short spoken summary of what's new, with the real messages, images and videos on screen.

“Tell the team we ship Friday.”

Post and reply

Posts go out under your name and look like you wrote them. Reply, react, pin, start threads.

“Did everything go through?”

Track what you asked

Every request has a live status: working, replied, done, or waiting on you.

“Undo.”

Take it back

One word undoes the last thing it did: a post, a thread, a reaction, a rename.

“Tell me when Leo replies.”

Hear when it's done

Get told when someone replies to you. With your phone locked, Discord pings you instead.

“Um… hang on.”

Ignores small talk

Filler and background chatter are skipped, so the people around you won't post by accident.

Set up in about ten minutes.

It runs on a computer you own and your phone connects to it privately. Nothing is hosted for you, and nothing is shared.

Add a Discord bot

Create a bot in the Discord developer portal and invite it to your server.

Run the server

Clone the repo, add your bot token and server ID, and sign in to ChatGPT once with the Codex CLI.

Open it on your phone

Use Tailscale to reach your computer privately. Add the page to your home screen, then tap and talk.

# needs Node 20+
REPO=harrythentrepreneur/discord-voice-commander
npx degit $REPO dvc
cd dvc && npm install

# add your bot token + server ID
cp .env.example .env

# sign in to ChatGPT (for the voice)
codex login

npm start

# in a second terminal: phone access
tailscale serve 3077

Safe by default.

It acts with your server's permissions, so the guard rails are built in.

Private, not publicListens only on your computer. Reach it through your private Tailscale network, never the open internet.

No destructive actionsIt can't delete other people's messages, ban members or change permissions. The only delete is undoing its own last action.

Only posts when you askA post goes out only if you clearly asked for one. Anything else waits for a spoken yes.

Your keys stay homeTokens stay on your computer and never reach the browser. It uses your own ChatGPT sign-in and needs no extra API key.

No double postsThe same message to the same channel within a minute is sent once.
